# StreamPulse FAQ

## 115 扫码没有反应

1. 确认版本不低于 1.8.1。
2. 微信小程序扫码选“微信小程序”，支付宝选“支付宝小程序”，115 App 选 Android/iOS。
3. 二维码约 5 分钟有效，过期后重新生成。
4. 仍然失败时改用 Cookie 登录。

## 115 返回 403 / 405

115 可能限制当前出口 IP 或触发风控：

- 403：常见于香港等地区 IP，换出口或代理。
- 405：短时间请求过多，暂停操作并换设备扫码。
- 不要频繁刷新二维码。

## 整理前必须注意

- 必须先对媒体库执行一次全量同步。
- 待整理目录应在媒体库目录之外，避免整理时重复扫描。
- 目标分类目录由 StreamPulse 自动创建，不需要填写云盘目录 ID。
- 先扫描预览，再执行整理。
- 洗版旧文件进入 115/123 回收站，不会直接永久删除。

## 整理后没有 STRM

检查：

1. 整理页是否选择了“整理后同步媒体库”；
2. 该媒体库的 **STRM 生成地址** 是否填写；
3. 媒体库的源目录是否包含整理后的 `/Media`；
4. 运行记录里的扫描与生成数量。

## 附属文件没有下载

- 检查媒体库“下载附属文件”开关。
- 单文件超过 30MB 会跳过。
- 115/123 直链解析失败时会在任务日志里记录。

## 115 生活事件增量

- 需要先完成一次全量同步。
- 媒体库必须设置实时同步间隔并开启“115 生活事件增量”。
- 当前实现是检测到事件后触发增量扫描，不是逐事件定位。

## 主题显示异常

- 默认白天模式，右上角可切换夜间。
- 更新镜像后强制刷新浏览器缓存。
- 如果仍有局部深色，请提交页面名/截图。
